# Sales & Profit Analysis Dashboard

## 📊 Project Overview

An interactive **Excel Sales & Profit Analysis Dashboard** created using the Vrinda Store sales dataset.

The project transforms raw store sales data into meaningful business insights by analyzing customer demographics, sales channels, product categories, order status, quantity, revenue, and geographic performance.

The dashboard is designed to provide an easy-to-understand view of sales performance and help identify important business trends.

## 🛠️ Tools & Technologies

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Excel formulas
* Data cleaning and organization
* Dashboard design
* Data analysis and visualization

## 📁 Dataset

The dataset contains information related to store orders, including:

* Order ID
* Customer ID
* Gender
* Age
* Order Date
* Order Status
* Sales Channel
* SKU
* Product Category
* Size
* Quantity
* Amount
* Shipping City
* Shipping State
* Postal Code
* Country
* B2B indicator

## 📈 Analysis Performed

The project analyzes:

* Overall sales performance
* Order volume
* Sales by gender
* Sales by age group
* Product category performance
* Sales by state and city
* Sales by sales channel
* Order status distribution
* Quantity and revenue trends
* Customer purchasing patterns

## 📊 Dashboard Features

The dashboard provides interactive analysis using:

* PivotCharts
* Slicers
* Filters
* KPI-style summaries
* Category-wise analysis
* Customer demographic analysis
* Geographic analysis
* Sales channel analysis

Users can interact with the dashboard to filter the analysis and explore different aspects of store performance.

## 🎯 Project Objective

The main objective of this project is to demonstrate how Microsoft Excel can be used to transform raw sales data into an interactive business dashboard and generate useful insights for decision-making.
